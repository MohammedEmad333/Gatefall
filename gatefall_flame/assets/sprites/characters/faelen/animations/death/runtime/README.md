# Faelen Death Runtime

Approved runtime contract for Faelen's death animation.

- 8 frames
- 384×273 PNG
- transparent RGBA
- 130 ms per frame
- 1040 ms total
- filenames: `faelen_death_01.png` through `faelen_death_08.png`
- final frame remains on the ground; the sequence does not loop
- use only when the complete frame set is present; otherwise fall back to the neutral sprite
- preserve Faelen's canonical face, platinum hair, green cloak, dark/silver armor, red-brown belt, sword, and warden shield
