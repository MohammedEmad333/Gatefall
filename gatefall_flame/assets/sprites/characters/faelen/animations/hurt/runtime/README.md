# Faelen Hurt Runtime

Approved runtime contract for Faelen's hurt animation.

- 6 frames
- 384×273 PNG
- transparent RGBA
- 110 ms per frame
- 660 ms total
- filenames: `faelen_hurt_01.png` through `faelen_hurt_06.png`
- use only when the complete frame set is present; otherwise fall back to the neutral sprite
- preserve Faelen's canonical face, platinum hair, green cloak, dark/silver armor, red-brown belt, sword, and warden shield
