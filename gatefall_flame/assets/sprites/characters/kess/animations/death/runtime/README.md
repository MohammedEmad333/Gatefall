# Kess death runtime frames

Reserved runtime contract for Kess's approved death animation.

- Expected frame count: 8
- File pattern: `kess_death_01.png` … `kess_death_08.png`
- Encoding: PNG / RGBA
- Background: transparent
- Frame cadence: 130 ms
- All frames in the set must exist before the runtime will use the animation.
- Do not place concept sheets, generated drafts, contact-pose experiments, or non-approved identity variants here.

Until an approved complete frame set is added, Gatefall safely falls back to `assets/sprites/characters/kess.png`.
