# Kess art assets

Kess production art and animation references.

## Canonical assets

- `kess_master.png` — canonical transparent full-body Kess reference with Twin Ember Blades.
- `weapons/kess_twin_ember_blades.png` — isolated Twin Ember Blades.
- `reference/kess_character_reference_v1.webp` — turnaround/reference sheet.
- `reference/kess_hero_card.webp` — approved hero/concept card.
- `animations/idle/kess_idle_sprite_sheet_v1.png` — current approved idle sprite sheet.
- `rig/kess_rig_cutout_v5.webp` — current cutout/rig development reference.

## Status

The generated run-cycle attempts are intentionally **not** checked in because the character identity and/or run mechanics were not consistent enough for production use.

Treat `kess_master.png` as the visual identity source of truth while the cutout rig and animation pipeline are refined.
