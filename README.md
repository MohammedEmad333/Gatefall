# Gatefall

Idle action-RPG × romance simulation. See `docs/HANDOFF.md` for the full
project handoff (premise, locked design decisions, build progress).

## Layout

- `docs/` — design docs (story bible, character routes, combat spec,
  dialogue data model, project handoff).
- `gatefall_dialogue_engine/` — pure-Dart branching dialogue engine, plus
  all five companion routes as JSON data.
- `gatefall_flame/` — Flutter + Flame combat prototype and balance tests.
