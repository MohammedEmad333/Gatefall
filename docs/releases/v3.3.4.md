# Gatefall 3.3.4 — release notes

## Highlights
- Faelen: approved hurt and death animations, complete-frame fallback, and playback tests.
- Momo: approved hurt animation with runtime asset registration and tests.
- Saves: fallback to the previous valid save if the primary JSON is corrupted; clearing progress removes both primary and backup.
- CI: Flutter analyzer errors now fail the build.
- Dialogue engine: standalone Dart tests run as part of the APK workflow.

## Validation before publishing
- Wait for the full PR workflow to pass (analysis, Dart tests, Flutter tests, Android release APK).
- Android signing secrets must be configured for a GitHub Release to be published from main.
- Test upgrading an installed APK without losing its save; test fallback recovery with a damaged primary save.
- Review Faelen and Momo animation sequencing on a real device.

The build number is increased from 9 to 10 so Android can install this version as an update.
